# v0.15 扫描摘要追加访问路径/定位信息 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v0.14 的终端扫描摘要每条 critical/high/suspicious 末尾追加访问路径（`path=[...]`）或定位信息（`trigger=`/`pipeline=`/`class=`），让应急人员一眼拿到封堵/溯源/清理所需。

**Architecture:** 纯 attach 端，扩展 `ScanSummaryPrinter`。逐条打印 finding 时，按 `type` 从 `attributes` 取对应字段，格式化成一段追加到行尾。有字段才追加，无则该行不变。复用现有 Jackson JsonNode。

**Tech Stack:** Java 8，JUnit 5，Jackson，Maven（`./mvnw.cmd`），attach 模块。

参考 spec：`docs/superpowers/specs/2026-06-04-v0.15-summary-paths-design.md`

**关键既有事实（已确认）：**
- `ScanSummaryPrinter.print(PrintStream out, String reportPath, int pid)` 现有逐条打印循环（line 45-54）：
  ```java
  for (String level : SHOWN_LEVELS) {
      for (JsonNode f : findings) {
          if (!level.equals(f.path("level").asText(""))) continue;
          String type = f.path("type").asText("");
          JsonNode cn = f.path("className");
          String className = (cn.isNull() || cn.isMissingNode()) ? "<null>" : cn.asText();
          int score = f.path("score").asInt(0);
          out.println("  [" + level + "] " + type + "  " + className + "  score=" + score);
      }
  }
  ```
- 现有 import：`JsonNode`、`ObjectMapper`、`File`、`PrintStream`。`MAPPER` 静态常量已存在。
- `JsonNode.path(key)` 缺失返回 MissingNode；`.isArray()`、`.isMissingNode()`、`.isNull()`、`.asText("")`、`.asInt(0)` 均安全不抛。
- finding.attributes 在 JSON 里是嵌套对象（`f.path("attributes").path("urlPatterns")`）。
- 各类型 attributes 字段（spec §2.1，已确认）：
  - tomcat-filter → attributes.urlPatterns (数组)
  - tomcat-servlet → attributes.mappings (数组)
  - spring-mapping → attributes.pattern (字符串)
  - spring-interceptor → attributes.includePatterns (数组或字符串) + attributes.excludePatterns (可选)
  - agent-bytecode-tampered → attributes.injectedStrings (数组，可能很多)
  - tomcat-listener-request/session/context/other → attributes.listenerKind (字符串: request/session/context/other)
  - tomcat-valve → attributes.pipelineIndex (整数)
  - agent-transformer → attributes.transformerClass (字符串)
  - agent-dynamic-class / class-servlet / class-filter 等 → 无对应字段 → 不追加

(b) 在类内新增 helper 方法：
```java
    /**
     * Appends an access-path or location hint for the finding, based on its type:
     * URL-bound types get {@code path=[...]}; event/pipeline/transform types that have no URL get
     * {@code trigger=}/{@code pipeline=}/{@code class=} instead; types with no locator get nothing.
     * injectedStrings (Behinder redefine) can be long, so it is truncated to the first 5 entries.
     */
    private static void appendLocation(StringBuilder line, String type, JsonNode attrs) {
        if (attrs == null || attrs.isMissingNode() || !attrs.isObject()) return;
        if ("tomcat-filter".equals(type)) {
            appendListPath(line, attrs.path("urlPatterns"), Integer.MAX_VALUE);
        } else if ("tomcat-servlet".equals(type)) {
            appendListPath(line, attrs.path("mappings"), Integer.MAX_VALUE);
        } else if ("spring-mapping".equals(type)) {
            JsonNode p = attrs.path("pattern");
            if (!p.isMissingNode() && !p.isNull() && !p.asText("").isEmpty()) {
                line.append("  path=").append(p.asText());
            }
        } else if ("spring-interceptor".equals(type)) {
            appendListPath(line, attrs.path("includePatterns"), Integer.MAX_VALUE);
            JsonNode ex = attrs.path("excludePatterns");
            String exStr = formatList(ex, Integer.MAX_VALUE);
            if (exStr != null) line.append("  exclude=").append(exStr);
        } else if ("agent-bytecode-tampered".equals(type)) {
            appendListPath(line, attrs.path("injectedStrings"), 5);
        } else if (type != null && type.startsWith("tomcat-listener-")) {
            JsonNode k = attrs.path("listenerKind");
            if (!k.isMissingNode() && !k.isNull() && !k.asText("").isEmpty()) {
                line.append("  trigger=").append(k.asText());
            }
        } else if ("tomcat-valve".equals(type)) {
            JsonNode idx = attrs.path("pipelineIndex");
            if (!idx.isMissingNode() && !idx.isNull()) {
                line.append("  pipeline=").append(idx.asText());
            }
        } else if ("agent-transformer".equals(type)) {
            JsonNode c = attrs.path("transformerClass");
            if (!c.isMissingNode() && !c.isNull() && !c.asText("").isEmpty()) {
                line.append("  class=").append(c.asText());
            }
        }
        // other types (agent-dynamic-class, class-*) → no locator segment
    }

    /** Appends {@code  path=[...]} from a list node, truncating to {@code max} entries. No-op if empty/not array. */
    private static void appendListPath(StringBuilder line, JsonNode listNode, int max) {
        String s = formatList(listNode, max);
        if (s != null) line.append("  path=").append(s);
    }

    /**
     * Formats a JSON node as {@code [a, b, c]}. If it is an array longer than {@code max}, shows the
     * first {@code max} entries plus {@code ...(+N more)}. If the node is a non-empty scalar, wraps it
     * as {@code [value]}. Returns null when there is nothing to show (missing/null/empty array).
     */
    private static String formatList(JsonNode node, int max) {
        if (node == null || node.isMissingNode() || node.isNull()) return null;
        if (node.isArray()) {
            int n = node.size();
            if (n == 0) return null;
            StringBuilder sb = new StringBuilder("[");
            int shown = Math.min(n, max);
            for (int i = 0; i < shown; i++) {
                if (i > 0) sb.append(", ");
                sb.append(node.get(i).asText());
            }
            if (n > max) sb.append(", ...(+").append(n - max).append(" more)");
            sb.append("]");
            return sb.toString();
        }
        // non-array scalar (e.g. includePatterns reflected as a single string)
        String t = node.asText("");
        if (t.isEmpty()) return null;
        return "[" + t + "]";
    }
```

## Self-Review 结论

- **Spec 覆盖**：spec §2.1 映射表 → Task 1 appendLocation；§2.2 格式化（List/标量/截断）→ formatList；§2.3 健壮性 → 各 helper 的 isMissingNode/isNull/isArray 守卫 + missing_attributes 测试；§4.1 单测 → Task 1 的 11 个测试逐类型覆盖；§4.2 实地 → Task 3；§4.3 DoD → Task 2。全覆盖。
- **占位符**：无 TBD/TODO；每步含完整代码与命令。
- **类型一致性**：`appendLocation(StringBuilder, String type, JsonNode attrs)`、`appendListPath(StringBuilder, JsonNode, int max)`、`formatList(JsonNode, int max)→String|null` 三个 helper 签名前后一致；listener 用 `type.startsWith("tomcat-listener-")` 匹配 request/session/context/other 四种子类型，与 §2.1 一致。
- **关键设计点**：formatList 对非数组标量也兼容（spring-interceptor 的 include/exclude 反射读出可能是字符串）→ 包成 `[value]`；空数组/缺失返回 null → 不追加段。injectedStrings max=5，其它 path 用 Integer.MAX_VALUE 不截断。
