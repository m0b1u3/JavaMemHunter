# v0.14 attach 端扫描摘要 + 默认输出路径 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** scan 完成后在用户 attach 终端打印精简摘要（逐条 critical/high/suspicious + low 计数），且不带 `--output` 时默认把报告写到 attach 进程当前目录。

**Architecture:** 纯 attach 端改动。新增 `ScanSummaryPrinter`（读 scan.json → 格式化 → 打印到 PrintStream）。`AttachMain` 在 scan 命令时：用户没传 `--output` 就注入默认绝对路径，传了就转绝对路径；agent 跑完后调 printer 打摘要。复用 attach 已有的 Jackson（`com.fasterxml.jackson.databind.ObjectMapper`）。

**Tech Stack:** Java 8，JUnit 5，Jackson，Maven（`./mvnw.cmd`），attach 模块。

参考 spec：`docs/superpowers/specs/2026-06-04-v0.14-scan-summary-design.md`

**关键既有事实（已确认）：**
- `AttachMain.run(String[] args, InputStream input, PrintStream out, PrintStream err, AttachExecutor executor)` 是主入口；测试直接调它。
- scan 走法：`args[0]=pid, args[1]=agentJar, args[2]="scan", 后续为 options`。当前 scan 分支只是 `executor.run(pid, agentJar, agentArgs.toString())` 然后 `return 0`（verify/clean 有额外分支）。
- `agentArgs` 由 `args[2..]` 用空格拼成的 StringBuilder。
- `parseOptions(args, 3)` 返回 `Map<String,String>`，`--output x` → `{output:x}`，无值的 `--foo` → `{foo:true}`。
- scan.json 结构：顶层 `summary.{critical,high,suspicious,low}`（int）、`findings[]` 每条 `{level, type, className(可能null), score, name, id, ...}`、`target.pid`。
- attach 已用 Jackson：`new com.fasterxml.jackson.databind.ObjectMapper().readValue(file, X.class)`（AttachMain 读 VerifyResult/CleanResult）。
- 测试既有：`RecordingExecutor extends AttachExecutor`（字段 `boolean called`、`String agentArgs`）；`run(String[], String stdin, RecordingExecutor)` helper 把 out/err 丢进 ByteArrayOutputStream。
- `new File(name).getAbsolutePath()` 用的是 attach 进程的 `user.dir`（CWD）——正是要的默认目录。

```java
package com.memhunter.attach;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;

import java.io.File;
import java.io.PrintStream;

/**
 * Reads a scan report JSON and prints a concise summary to the user's attach-side console:
 * the per-level counts, then each critical/high/suspicious finding on one line
 * ({@code [level] type className score=N}); "low" findings are counted only, not listed.
 * The full JSON report (which still contains every finding for forensics) is referenced by path.
 *
 * <p>Failure to read or parse the report never throws — it prints a single degraded line so the
 * scan command still succeeds.
 */
public final class ScanSummaryPrinter {

    private ScanSummaryPrinter() {}

    private static final String[] SHOWN_LEVELS = {"critical", "high", "suspicious"};

    public static void print(PrintStream out, String reportPath, int pid) {
        JsonNode root;
        try {
            root = new ObjectMapper().readTree(new File(reportPath));
            if (root == null) throw new IllegalStateException("empty report");
        } catch (Throwable t) {
            out.println("[memhunter] scan finished, report at " + reportPath
                    + " (summary unavailable: " + t.getClass().getSimpleName() + ")");
            return;
        }

        JsonNode summary = root.path("summary");
        out.println("[memhunter] scan summary (PID " + pid + "):");
        out.println("  critical: " + summary.path("critical").asInt(0)
                + "  high: " + summary.path("high").asInt(0)
                + "  suspicious: " + summary.path("suspicious").asInt(0)
                + "  low: " + summary.path("low").asInt(0));

        JsonNode findings = root.path("findings");
        if (findings.isArray()) {
            for (String level : SHOWN_LEVELS) {
                for (JsonNode f : findings) {
                    if (!level.equals(f.path("level").asText(""))) continue;
                    String type = f.path("type").asText("");
                    JsonNode cn = f.path("className");
                    String className = (cn.isNull() || cn.isMissingNode()) ? "<null>" : cn.asText();
                    int score = f.path("score").asInt(0);
                    out.println("  [" + level + "] " + type + "  " + className + "  score=" + score);
                }
            }
        }
        out.println("[memhunter] full report: " + reportPath);
    }
}
```

- [ ] **Step 3: 实现默认 output 注入**

在 `AttachMain.run` 中，定位到拼好 `agentArgs` 之后、`String command = args[2];` 与 `parseOptions` 之后。新增一个辅助静态方法，并在 scan 命令时改写 agentArgs。

先加静态方法（放在类内，paramaters 用现有 import 的 File）：

```java
    /**
     * For scan: ensure agentArgs carries an absolute --output path. If the user supplied --output,
     * make it absolute; otherwise inject a default under the attach process CWD. Returns the
     * absolute report path (for the summary printer). Non-scan commands return null and leave
     * agentArgs unchanged (handled by caller).
     */
    static String resolveScanOutput(java.util.Map<String, String> options) {
        String userOut = options.get("output");
        String abs;
        if (userOut != null && !"true".equals(userOut)) {
            abs = new java.io.File(userOut).getAbsolutePath();
        } else {
            abs = new java.io.File("memhunter-scan-" + System.currentTimeMillis() + ".json")
                    .getAbsolutePath();
        }
        return abs;
    }
```

然后在 `run` 里把 scan 分支改造。当前末尾是：
```java
        executor.run(pid, agentJar, agentArgs.toString());
        if ("verify".equals(command)) {
            return printVerifyResult(out, evidenceDir(options), requireOption(options, "id")) ? 0 : 1;
        }
        return 0;
```
改为（在通用 `executor.run` 之前，对 scan 单独处理）：
```java
        if ("scan".equals(command)) {
            String reportPath = resolveScanOutput(options);
            String scanArgs;
            if (options.containsKey("output")) {
                // replace the user-supplied (possibly relative) --output value with the absolute one
                scanArgs = agentArgs.toString().replaceFirst(
                        "--output\\s+\\S+",
                        java.util.regex.Matcher.quoteReplacement("--output " + reportPath));
            } else {
                scanArgs = agentArgs.toString() + " --output " + reportPath;
            }
            executor.run(pid, agentJar, scanArgs);
            ScanSummaryPrinter.print(out, reportPath, parseIntSafe(pid));
            return 0;
        }
        executor.run(pid, agentJar, agentArgs.toString());
        if ("verify".equals(command)) {
            return printVerifyResult(out, evidenceDir(options), requireOption(options, "id")) ? 0 : 1;
        }
        return 0;
```

加 `parseIntSafe` 辅助（pid 是 String，printer 要 int；非法则用 -1）：
```java
    private static int parseIntSafe(String s) {
        try { return Integer.parseInt(s.trim()); } catch (Exception e) { return -1; }
    }
```

注意：`replaceFirst` 用了正则，`--output\s+\S+` 匹配 `--output <值>`；替换值用 `Matcher.quoteReplacement` 防止路径里的 `\`（Windows）被当成正则替换转义。`scan` 命令一定有 args[2]="scan"，agentArgs 以 "scan" 开头，正则只动 --output 段。
