## 2. 目标与非目标

### 2.1 目标

1. 引入基线对比能力：扫描时与历史 ScanReport 对比，发现"新增"finding
2. 新增 `baseline-new` 评分规则（+4），对所有 type 生效
3. 扫描报告 Summary 新增 `baselineNewCount` 和 `baselineMatchedCount` 字段
4. CLI 新增 `--baseline <file>` 选项
5. 修复 Listener/Interceptor 的 Finding ID 跨重启不稳定问题（移除 identityHashCode）
6. 处理 v0.4 评审遗留：
   - `BytecodeAnalysis.methodCalls` 改为 immutable
   - 添加 `hasMethodCallByOwnerPrefix` helper（消除 BytecodeCryptoRule 内联 set 迭代）
   - `BytecodeAnalysis.hasMethodCall` substring 语义 Javadoc 明确化
   - `BytecodeAnalyzer` 支持 INVOKEDYNAMIC（识别 JDK 9+ lambda 中的 Runtime.exec 等）
7. **核心验收**：注入后扫描，3 个 Fake 容器层 finding 全部 score ≥ 各自 v0.4 + 4（FakeFilter 25, FakeServlet 21, FakeInterceptor 23）且命中 baseline-new

### 2.2 非目标

- 不做清理操作（v0.6）
- 不发明独立 baseline 文件格式（复用 ScanReport JSON）
- 不处理"消失的 finding"（YAGNI）
- 不做 HTML / Markdown 报告
- 不重构 Provider strategies / 抽取 FindingClassMetadata（v0.2 评审遗留留 v0.6+）
- 不引入新的依赖

### 3.2 关键决策

| 决策点 | v0.5 选择 | 理由 |
|---|---|---|
| 基线存储 | 复用 ScanReport JSON | 单一职责，无新格式 |

### 4.1 agentmain 流程（v0.5 增量）

```text
1. AgentArgs.parse
   ├─ --output, --whitelist, --explain (已有)
   └─ --baseline <file>  (新)

2. Whitelist 加载（不变）

3. 元信息采集（不变）

   │   └─ 成功 → BaselineIndex(findingIds)

7. RuleEngine.evaluate(findings, ctx)
   - 既有 17 条规则
   - + baseline-new (+4)

8. Summary 统计（扩展）
   - 既有：totalFindings / critical / high / suspicious / low
   - 新增：
       baselineNewCount = count of findings hit baseline-new
       baselineMatchedCount = count of findings whose id is in baselineIndex

9. JsonReportWriter.write()（不变）
```

### 4.2 核心数据结构

#### BaselineIndex（新建）

```java
public class BaselineIndex {
    private final Set<String> findingIds;

    public BaselineIndex(Set<String> findingIds) {
        this.findingIds = Collections.unmodifiableSet(new HashSet<>(findingIds));
    }

    public static BaselineIndex empty() {
        return new BaselineIndex(Collections.<String>emptySet());
    }

    public boolean contains(String findingId) {
        return findingId != null && findingIds.contains(findingId);
    }

    public boolean isEmpty() {
        return findingIds.isEmpty();
    }

    public int size() {
        return findingIds.size();
    }
}
```

#### BaselineLoader（新建）

```java
public final class BaselineLoader {
    private BaselineLoader() {}

    /**
     * Load baseline from a previous ScanReport JSON file.
     * On any failure (IO, parse, malformed), returns empty index.
     * The caller can add a partialError entry based on whether the result is empty.
     */
    public static BaselineIndex load(String path) {
        if (path == null) return BaselineIndex.empty();
        File f = new File(path);
        if (!f.exists()) return BaselineIndex.empty();
        try {
            ObjectMapper mapper = new ObjectMapper();
            JsonNode root = mapper.readTree(f);
            JsonNode findings = root.get("findings");
            if (findings == null || !findings.isArray()) return BaselineIndex.empty();
            Set<String> ids = new HashSet<>();
            for (JsonNode finding : findings) {
                JsonNode id = finding.get("id");
                if (id != null && id.isTextual()) ids.add(id.asText());
            }
            return new BaselineIndex(ids);
        } catch (Throwable t) {
            return BaselineIndex.empty();
        }
    }
}
```

#### BaselineNewRule（新建）

```java
public class BaselineNewRule implements ScoringRule {

    @Override public String name() { return "baseline-new"; }

    @Override
    public int evaluate(Finding finding, ScanContext ctx) {
        if (finding == null || finding.id == null) return 0;
        if (ctx == null || ctx.baselineIndex == null) return 0;
        if (ctx.baselineIndex.isEmpty()) return 0;
        return ctx.baselineIndex.contains(finding.id) ? 0 : 4;
    }
}
```

### 4.3 Listener/Interceptor ID 稳定性修复

**v0.4 当前**：

```java
// TomcatListenerScanner.java
f.id = FindingIdGenerator.generate(f.type, f.className,
        Integer.toHexString(System.identityHashCode(listener)));

// SpringInterceptorScanner.java
f.id = FindingIdGenerator.generate(TYPE, f.className,
        Integer.toHexString(System.identityHashCode(interceptor)));
```

**v0.5 修复**：

```java
// TomcatListenerScanner.java
f.id = FindingIdGenerator.generate(f.type, f.className, "");

// SpringInterceptorScanner.java
f.id = FindingIdGenerator.generate(TYPE, f.className, "");
```

**影响**：同一 className 的多个 listener/interceptor 实例会合并为同一 Finding ID（即同一个 Finding 条目）。这接受为合理行为——内存马检测关心"哪个类被注册"，不关心"注册了几次"。

### 4.4 BytecodeAnalysis 加固

```java
public class BytecodeAnalysis {

    /**
     * Immutable view of all method calls found in the class's bytecode.
     * Each entry is "owner#name" where owner is in ASM internal name format
     * (slashes, e.g. "java/lang/Runtime") and name is the raw method name.
     */
    public final Set<String> methodCalls;

    public BytecodeAnalysis(Set<String> methodCalls) {
        this.methodCalls = Collections.unmodifiableSet(new HashSet<>(methodCalls));
    }

    /**
     * True if any method call matches the owner exactly AND the name CONTAINS namePattern.
     * Note: name match is substring, not equals. "exec" matches "exec", "execute", "execAsync".
     * This substring behavior is intentional for the broad detection use case where
     * attackers may use minor name variations.
     */
    public boolean hasMethodCall(String owner, String namePattern) { ... }

    /**
     * True if any method call's name contains namePattern (substring), regardless of owner.
     */
    public boolean hasMethodCallByName(String namePattern) { ... }

    /**
     * True if any method call's owner starts with ownerPrefix.
     * Useful for matching any class under a parent package or class
     * (e.g. "java/util/Base64" matches Base64, Base64$Encoder, Base64$Decoder).
     */
    public boolean hasMethodCallByOwnerPrefix(String ownerPrefix) {
        for (String call : methodCalls) {
            int sep = call.indexOf('#');
            if (sep < 0) continue;
            if (call.substring(0, sep).startsWith(ownerPrefix)) return true;
        }
        return false;
    }
}
```

`BytecodeCryptoRule` 改造：

```java
if (a.hasMethodCall("javax/crypto/Cipher", "doFinal")) return 2;
if (a.hasMethodCallByOwnerPrefix("java/util/Base64")) return 2;
return 0;
```

### 4.5 BytecodeAnalyzer INVOKEDYNAMIC 支持

```java
@Override
public MethodVisitor visitMethod(...) {
    return new MethodVisitor(ASM_API) {
        @Override
        public void visitMethodInsn(int opcode, String owner, String name, String desc, boolean isIface) {
            methodCalls.add(owner + "#" + name);
        }

        @Override
        public void visitInvokeDynamicInsn(String name, String descriptor,
                                            Handle bootstrap, Object... bootstrapArgs) {
            // bootstrap args 通常包含 Handle 引用 lambda body 的合成方法
            // 或引用真正被调用的方法（LambdaMetafactory case）
            for (Object arg : bootstrapArgs) {
                if (arg instanceof Handle) {
                    Handle h = (Handle) arg;
                    methodCalls.add(h.getOwner() + "#" + h.getName());
                }
            }
        }
    };
}
```

效果：
- JDK 11+ 的 `() -> Runtime.getRuntime().exec("nope")` lambda 中包含的 `Runtime#exec` 被识别
- 字符串拼接 `"hello" + cmd` 通过 `StringConcatFactory.makeConcatWithConstants` —— bootstrap args 不含 owner 字段，不会误报为可疑 method call

## 5. 错误处理

- `BaselineLoader.load` 内部全程 catch Throwable，失败返回 empty index
- `MemHunterAgent.agentmain` 中检查 `baselineIndex.isEmpty()` 和 `args.options.get("baseline") != null` 决定是否记录 partialError
- BaselineNewRule 在 baselineIndex == null 或 isEmpty 时不触发
- 任何字节码规则在 `ctx.bytecodeOf` 返回 null 时返回 0（不变）

### 6.3 验收脚本

```python
import json
clean = json.load(open(r"C:\temp\v05-clean.json"))
after = json.load(open(r"C:\temp\v05-after.json"))

    return next((f for f in r['findings']
                 if f.get('name') == name and f.get('type','').startswith(type_prefix)), None)
```
