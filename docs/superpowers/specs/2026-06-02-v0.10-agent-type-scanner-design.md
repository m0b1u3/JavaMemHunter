# v0.10 设计：Agent 型内存马检测 + 误报降低

**日期**：2026-06-02  
**前置版本**：v0.9.1（`--add-opens` JDK 17 修复，CI scan E2E 通过）  
**背景**：实战测试发现两个问题：
1. 冰蝎 AgentNoFile 型内存马无法被检测（agent 走字节码注入，不注册 Filter/Servlet）
2. Tomcat examples webapp 的 `HelloWorldExample`、`async0/1/2/3` 等正常 Servlet 被误报为 critical，误报率极高（87 findings 中 86 个为噪音）

---

## 1. 目标 & 非目标

### 1.1 目标

1. **降低误报**：用 Tomcat 内部 API `wasCreatedDynamicServlet()` 和 `FilterDef.dynamic` 字段，
   区分 web.xml 静态声明的组件 vs 运行时动态注册的组件。只对动态注册的
   Filter/Servlet 触发 `runtime-only` 加分，web.xml 声明的不加分。
   目标：`HelloWorldExample`、`async0/1/2/3` 等从 critical 降到 low 以下，
   不再出现在 high/critical 列表。

2. **Agent 型内存马检测**：新增 `AgentTypeScanner`，含三个子检测器：
   - `TransformerScanner` — 扫描 `ClassFileTransformer` 注册列表，非白名单 Transformer
     → finding `agent-transformer`（high, score=10）
   - `DynamicClassScanner` — 扫描 `codeSource==null` 且 classLoader 非标准的已加载类，
     字节码评分 → finding `agent-dynamic-class`
   - `BytecodeTamperScanner` — 对 5 个关键类做内存字节码 vs JAR 字节码 SHA-256 对比，
     不一致 → finding `agent-bytecode-tampered`（critical, score=15）

### 1.2 非目标

- 不清理 Agent 型内存马（需要热替换字节码，风险极高，推迟到 v0.11）
- 不支持可配置白名单（内置白名单覆盖主流 APM 工具）
- 不解析 web.xml 文件（直接用 Tomcat 内部 API，更可靠）
- 不检测 Spring Bean 注入型（已在 v0.8 scope 外）
- 不覆盖 WebFlux 应用

## 2. 架构变化

### 2.1 文件结构

```
新增：

    AgentTypeScanner.java          对外入口，聚合三个子 scanner
    TransformerScanner.java        扫 ClassFileTransformer 列表
    DynamicClassScanner.java       扫无 codeSource 的可疑已加载类
    BytecodeTamperScanner.java     字节码完整性校验

修改：
  agent/src/main/java/com/memhunter/agent/scanner/tomcat/
    TomcatFilterScanner.java       buildFinding 时标记 isDynamic
    TomcatServletScanner.java      buildFinding 时标记 isDynamic
  agent/src/main/java/com/memhunter/agent/scoring/rules/
    RuntimeOnlyRule.java           只对 isDynamic=true 生效
  agent/src/main/java/com/memhunter/agent/
    MemHunterAgent.java            scan() 末尾接入 AgentTypeScanner
```

### 2.2 scan 流程变化

```
// 原有
all.addAll(tomcat.scanContexts(tomcatContexts, report));
all.addAll(spring.scan(..., report));

// v0.10 新增（末尾追加）
all.addAll(new AgentTypeScanner().scan(inst, report));
```

`AgentTypeScanner` 需要 `Instrumentation inst`，已在 `MemHunterAgent.agentmain` 中持有，
直接传入即可。

### 2.3 Finding 新 type

| type | level | score | 触发条件 |
|---|---|---|---|
| `agent-transformer` | high | 10 | 非白名单 ClassFileTransformer |
| `agent-dynamic-class` | suspicious~critical | 4~14 | codeSource=null + 非标准 classLoader + 字节码特征 |
| `agent-bytecode-tampered` | critical | 15 | 关键类内存字节码 ≠ JAR 字节码 |

Finding 模型不变（`f.attributes` Map 已存在）：
- `isDynamic`（Boolean）— TomcatFilter/Servlet finding 新增，用于 RuntimeOnlyRule 判断
- `transformerClass`（String）— agent-transformer finding 的 Transformer 类名
- `tamperedClass`（String）— agent-bytecode-tampered finding 的被篡改类名
- `memSize` / `diskSize`（Integer）— 字节码长度，辅助诊断

## 3. 误报修复：isDynamic 标记

### 3.1 Tomcat API

```
StandardContext.wasCreatedDynamicServlet(Servlet servlet) → boolean
  true  = addServlet() 动态注册（内存马或框架 programmatic 注册）
  false = web.xml / annotation 静态声明

FilterDef.dynamic (boolean field)
  true  = addFilter() 动态注册
  false = web.xml 静态声明
```

### 3.2 TomcatServletScanner 改动

`buildFinding()` 方法，在拿到 servlet 实例后：

```java
Optional<Object> instance = ReflectUtil.tryInvoke(wrapper, "getServlet");
if (instance.isPresent() && instance.get() != null) {
    Object servlet = instance.get();
    f.codeSource = codeSourceOf(servlet.getClass());
    f.classLoader = clName(servlet.getClass().getClassLoader());

    // v0.10 新增：isDynamic 标记
    // wasCreatedDynamicServlet(Servlet) 需要一个参数，用 tryInvokeWithArg
    boolean dyn = ReflectUtil.tryInvokeWithArg(context, "wasCreatedDynamicServlet", servlet)
            .map(v -> Boolean.TRUE.equals(v))
            .orElse(true);  // 找不到 API 时保守地视为动态（不降分）
    f.attributes.put("isDynamic", dyn);
}
```

**注意**：`ReflectUtil.tryInvoke` 目前不支持带参数的方法调用。需新增
`ReflectUtil.tryInvokeWithArg(Object target, String method, Object arg)` 重载。

### 3.3 TomcatFilterScanner 改动

从 `StandardContext.findFilterDef(filterName)` 拿 `FilterDef`，读 `dynamic` 字段：

```java
String filterName = f.name;  // already set
Optional<Object> filterDef = ReflectUtil.tryInvoke(context, "findFilterDef", filterName);
// findFilterDef 也需要 tryInvokeWithArg
filterDef.ifPresent(fd -> {
    Optional<Object> dyn = ReflectUtil.tryReadField(fd, "dynamic");
    f.attributes.put("isDynamic", Boolean.TRUE.equals(dyn.orElse(Boolean.TRUE)));
});
// 如果拿不到 filterDef，保守视为动态
if (!f.attributes.containsKey("isDynamic")) {
    f.attributes.put("isDynamic", Boolean.TRUE);
}
```

### 3.4 RuntimeOnlyRule 改动

```java
public int evaluate(Finding finding, ScanContext ctx) {
    // v0.10：web.xml 静态声明的 finding 不触发 runtime-only
    Object isDynamic = finding.attributes.get("isDynamic");
    if (Boolean.FALSE.equals(isDynamic)) return 0;
    // ... 原有逻辑不变
}
```

**向后兼容**：旧 finding（无 `isDynamic` 属性）视为 true，原有行为不变。

### 3.5 ReflectUtil 扩展

## 4. AgentTypeScanner — 三个子检测器

### 4.1 TransformerScanner

```java
public List<Finding> scan(Instrumentation inst, ScanReport report) {
    List<Finding> findings = new ArrayList<>();
    try {
        Field tmf = inst.getClass().getDeclaredField("mTransformerManager");
        tmf.setAccessible(true);
        Object tm = tmf.get(inst);
        Field mts = tm.getClass().getDeclaredField("mTransformers");
        mts.setAccessible(true);
        Object[] transformers = (Object[]) mts.get(tm);
        if (transformers == null) return findings;

        for (Object tr : transformers) {
            String cn = tr.getClass().getName();
            if (isKnownSafe(cn)) continue;
            Finding f = new Finding();
            f.type = "agent-transformer";
            f.name = cn;
            f.className = cn;
            f.score = 10;
            f.level = "high";
            f.attributes.put("transformerClass", cn);
            f.attributes.put("transformerLoader",
                tr.getClass().getClassLoader() != null
                    ? tr.getClass().getClassLoader().getClass().getName() : "bootstrap");
            f.id = FindingIdGenerator.generate("agent-transformer", cn, "");
            f.reasons.add("non-whitelist-transformer (+10)");
            findings.add(f);
        }
    } catch (Throwable t) {
        report.partialErrors.add(new ScanReport.PartialError(
            "TransformerScanner", "exception: " + t.getMessage()));
    }
    return findings;
}

private static final String[] SAFE_PREFIXES = {
    "org.apache.skywalking.", "com.taobao.arthas.", "com.navercorp.pinpoint.",
    "net.bytebuddy.", "org.jacoco.", "co.elastic.apm.", "com.newrelic.",
    "com.dynatrace.", "io.opentelemetry.", "com.memhunter."  // 自身
};

private boolean isKnownSafe(String className) {
    for (String prefix : SAFE_PREFIXES) {
        if (className.startsWith(prefix)) return true;
    }
    return false;
}
```

### 4.2 DynamicClassScanner

```java
private static final Set<String> STANDARD_LOADERS = new HashSet<>(Arrays.asList(
    "org.springframework.boot.loader.LaunchedURLClassLoader",
    "org.apache.catalina.loader.ParallelWebappClassLoader",
    "org.apache.catalina.loader.WebappClassLoader",
    "org.apache.jasper.servlet.JasperLoader",
    "java.net.URLClassLoader",
    "jdk.internal.loader.ClassLoaders$AppClassLoader",
    "sun.misc.Launcher$AppClassLoader",
    "sun.misc.Launcher$ExtClassLoader"
));

public List<Finding> scan(Instrumentation inst, ScanReport report) {
    List<Finding> findings = new ArrayList<>();
    try {
        for (Class<?> c : inst.getAllLoadedClasses()) {
            if (!isSuspicious(c)) continue;

            Finding f = new Finding();
            f.type = "agent-dynamic-class";
            f.name = c.getSimpleName();
            f.className = c.getName();
            f.classLoader = c.getClassLoader() != null
                ? c.getClassLoader().getClass().getName() : "bootstrap";
            f.attributes.put("isDynamic", Boolean.TRUE);

            // 字节码评分（复用现有 BytecodeAnalysis）
            int extraScore = scoreByBytecode(c.getName(), report);
            f.score = 4 + extraScore;
            f.level = RuleEngine.mapLevel(f.score);
            f.id = FindingIdGenerator.generate("agent-dynamic-class", c.getName(), "");
            f.reasons.add("no-code-source (+2)");
            f.reasons.add("unusual-classloader (+2)");
            if (extraScore > 0) f.reasons.add("malicious-bytecode-pattern (+" + extraScore + ")");
            findings.add(f);
        }
    } catch (Throwable t) {
        report.partialErrors.add(new ScanReport.PartialError(
            "DynamicClassScanner", "exception: " + t.getMessage()));
    }
    return findings;
}

private boolean isSuspicious(Class<?> c) {
    if (c.getClassLoader() == null) return false;  // bootstrap 类跳过
    try {
        java.security.ProtectionDomain pd = c.getProtectionDomain();
        if (pd == null) return false;
        java.security.CodeSource cs = pd.getCodeSource();
        boolean noSource = cs == null || cs.getLocation() == null;
        if (!noSource) return false;
        String loaderName = c.getClassLoader().getClass().getName();
        boolean unusualLoader = !STANDARD_LOADERS.contains(loaderName);
        String name = c.getName();
        boolean shortName = !name.contains(".") && name.length() <= 5;
        return unusualLoader || shortName;
    } catch (Throwable t) {
        return false;
    }
}
```

### 4.3 BytecodeTamperScanner

```java
private static final String[] TARGET_CLASSES = {
    "org.apache.catalina.core.ApplicationFilterChain",
    "org.apache.catalina.core.StandardContextValve",
    "org.apache.catalina.connector.CoyoteAdapter",
    "javax.servlet.http.HttpServlet",
    "org.springframework.web.servlet.DispatcherServlet"
};

public List<Finding> scan(Instrumentation inst, ScanReport report) {
    List<Finding> findings = new ArrayList<>();
    for (String cn : TARGET_CLASSES) {
        try {
            Class<?> clazz = findLoaded(inst, cn);
            if (clazz == null) continue;

            byte[] mem = captureBytes(inst, clazz);
            byte[] disk = readFromJar(clazz);
            if (mem == null || disk == null) continue;

            if (!Arrays.equals(mem, disk)) {
                Finding f = new Finding();
                f.type = "agent-bytecode-tampered";
                f.name = cn;
                f.className = cn;
                f.score = 15;
                f.level = "critical";
                f.attributes.put("tamperedClass", cn);
                f.attributes.put("memSize", mem.length);
                f.attributes.put("diskSize", disk.length);
                f.id = FindingIdGenerator.generate("agent-bytecode-tampered", cn, "");
                f.reasons.add("bytecode-differs-from-jar (+15)");
                findings.add(f);
            }
        } catch (Throwable t) {
            report.partialErrors.add(new ScanReport.PartialError(
                "BytecodeTamperScanner", cn + ": " + t.getMessage()));
        }
    }
    return findings;
}

private Class<?> findLoaded(Instrumentation inst, String name) {
    for (Class<?> c : inst.getAllLoadedClasses()) {
        if (name.equals(c.getName())) return c;
    }
    return null;
}

private byte[] captureBytes(Instrumentation inst, Class<?> clazz) throws Exception {
    final byte[][] captured = {null};
    ClassFileTransformer cap = (loader, name, c, pd, bytes) -> {
        if (c == clazz) captured[0] = bytes;
        return null;  // 不修改字节码
    };
    inst.addTransformer(cap, true);
    try {
        inst.retransformClasses(clazz);
    } finally {
        inst.removeTransformer(cap);
    }
    return captured[0];
}

private byte[] readFromJar(Class<?> clazz) throws Exception {
    String path = clazz.getName().replace('.', '/') + ".class";
    ClassLoader cl = clazz.getClassLoader();
    java.io.InputStream is = cl != null
        ? cl.getResourceAsStream(path)
        : ClassLoader.getSystemResourceAsStream(path);
    if (is == null) return null;
    try (java.io.ByteArrayOutputStream buf = new java.io.ByteArrayOutputStream()) {
        byte[] tmp = new byte[4096];
        int n;
        while ((n = is.read(tmp)) != -1) buf.write(tmp, 0, n);
        return buf.toByteArray();
    }
}
```

## 5. 测试策略

### 5.1 单元测试

**`TransformerScannerTest`**（TDD）：
- mock `Instrumentation`，`mTransformers` 含一个自定义 Transformer → 报 `agent-transformer`
- Transformer 类名以 `org.apache.skywalking.` 开头 → 不报（白名单命中）
- `mTransformers` 为空 → 返回空列表
- `mTransformerManager` 字段不存在 → 记 partialError，不抛

**`DynamicClassScannerTest`**（TDD）：
- codeSource=null + 自定义 classLoader → 报 `agent-dynamic-class`
- codeSource 有值 → 不报
- 类名 `"ab"`（极短）+ codeSource=null → 报
- 标准 classLoader（URLClassLoader）+ codeSource=null → 不报

**`BytecodeTamperScannerTest`**（TDD）：
- 内存字节码 == 磁盘字节码 → 不报
- 内存字节码 != 磁盘字节码 → 报 `agent-bytecode-tampered`，score=15，level=critical
- 目标类未加载 → 跳过，不报 partialError
- `retransformClasses` 抛异常 → 记 partialError，继续扫其他类

**`RuntimeOnlyRule` 改动测试**（扩展现有测试）：
- finding 带 `isDynamic=false` → `evaluate()` 返回 0
- finding 带 `isDynamic=true` → 返回原有正值
- finding 不带 `isDynamic`（旧数据兼容）→ 视为 true，返回原有正值

**`ReflectUtil.tryInvokeWithArg` 测试**：
- 正常调用带参数方法 → 返回结果
- 方法不存在 → 返回 `Optional.empty()`
- 方法调用抛异常 → 返回 `Optional.empty()`
