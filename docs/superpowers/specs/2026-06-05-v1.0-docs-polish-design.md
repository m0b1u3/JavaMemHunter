## 2. 改动（4 个文档）

### 2.1 README.md（英文，重点重写）

- **What**：顶部「能打什么马」马型表（用户视角）：
  - 冰蝎 Behinder Agent 型（HttpServlet 字节码篡改，redefineClasses）
  - 哥斯拉 Godzilla 伪装 Filter/Servlet 型（Jackson 改包名 org.apache.coyote.*）
  - JSP webshell（文件型，org.apache.jsp.* 反推 .jsp URL）
  - Tomcat Filter / Servlet / Listener / Valve 注入
  - Spring Interceptor / Mapping 注入
- **检测机制**段（技术视角）：容器注册扫描 + ClassScanner 全类扫描 + AgentTypeScanner 字节码
  篡改检测 + RuleEngine 评分 + MasqueradedPackageRule 伪装包名识别 + 依赖类降级 + JspPathResolver
  路径反推 + FindingDeduplicator 同类去重 + BenignComponentRule 误报抑制
- **Quick start**：保留现有 build/scan/clean 命令，scan 后加一段**脱敏真实扫描终端摘要**：
  ```
  [memhunter] scan summary (PID <pid>):
    critical: 4  high: 9  suspicious: 0  low: 67
    [critical] tomcat-filter  org.apache.coyote.JavaType  score=16  path=[/*]
    [critical] tomcat-filter  org.apache.coyote.deser.BeanDeserializerModifier  score=16  path=[/*]
    ... (4 registered Godzilla filter shells)
    [high] class-servlet  org.apache.coyote.util.EnumValues  score=8        (Jackson dependency class — downgraded)
    [high] class-servlet  org.apache.jsp.<obfuscated>_jsp  score=7  path=[/<obfuscated>.jsp]
    [high] tomcat-servlet  <null>  score=8  path=[/<shell-path>]
  [memhunter] full report: ./memhunter-scan-<timestamp>.json
  ```
- **新增「Reading the output」段**：摘要分层语义（critical=激活的真马、high=webshell/Servlet
  马/依赖类、suspicious、low=噪音不逐条列）+ 路径标注语义（path=[...] 可封堵的访问路径；
  trigger=/pipeline= 事件/管道触发无 URL；JSP 的 path 指向待删磁盘文件）
- 更新 **Supported environments**：加 Tomcat 9.0.94 实测、Behinder/Godzilla ground-truth 验证
- **Known limitations** 补两条：`--output` 路径不能含空格（agent 参数按空白切分）；antiAgent
  封 attach 通道时所有 attach 工具失效（premain 模式对抗留作后续）

## 3. 脱敏原则

- 类名保留（`org.apache.coyote.*` 是哥斯拉伪装特征，有教学价值；`org.apache.jsp.*` 同理）
- 访问路径用占位符：`/<obfuscated>.jsp`、`/<shell-path>`
- PID 用 `<pid>`，时间戳用 `<timestamp>`
- 不含任何真实主机名 / IP / 密钥
