# JavaMemHunter v0.4 — 字节码扫描设计

## 1. 概要

| 项 | 内容 |
|---|---|
| 版本 | v0.4 |
| 主线 | 5 条字节码规则 + ASM 9.7 依赖 + 评审遗留 #1（删 80 行死代码） |
| 不在范围 | 基线对比、HTML/Markdown 报告、清理操作、Provider chain 重构 |
| 前置完成 | v0.3 评分规则引擎已 merge 至 master（commit `f1cace5`） |
| 后续依赖 | v0.5 基线对比 + ClassLoadedContextProvider 进一步重构 |

## 2. 目标与非目标

### 2.1 目标

1. 引入 ASM 9.7 字节码解析能力，agent fat jar 增加 ~120KB
2. 增加 5 条字节码规则覆盖设计文档第 9 节字节码关键字：runtime-exec / process-builder / define-class / reflection-abuse / crypto
3. ScanContext 持有 `bytecodeOf(className)` 缓存，单次扫描每个类至多解析一次字节码
4. test-target-injector 中 FakeFilter/Servlet/Interceptor 添加 dead-code 验证字节码规则
5. **核心验收**：3 个 Fake 注入项 score ≥ 14 且 level=critical；total noise (high+critical) ≤ 8
6. 顺手清理评审遗留 #1：删除 ClassLoadedContextProvider 中约 80 行死代码

### 2.2 非目标

- 不做基线对比（v0.5）
- 不做评审遗留 #2/#3/#4（Provider chain 重构、FindingClassMetadata 抽取、ScanContext 解耦）
- 不做 HTML / Markdown 报告
- 不做清理操作
- 不全量扫描所有 loaded class 字节码——只扫 Finding 对应的类
- 不修改 Finding schema（v0.3 schema 完全兼容）

### 3.2 关键决策

| 决策点 | v0.4 选择 | 理由 |
|---|---|---|
| 字节码库 | ASM 9.7 | 业界标准，shaded 进 fat jar（+120KB） |
| 扫描范围 | 所有 Finding 对应的类 | 与 v0.3 finding pipeline 自然衔接，避免全量扫描开销 |
| 解析方式 | `MethodVisitor.visitMethodInsn` 精确匹配 owner + name | 比常量池字符串包含更精确，减少误报 |
| 失败处理 | 静默跳过，缓存 MISS sentinel | 不污染报告；CGLIB/JDK proxy 等"读不到字节码"是常态 |
| 缓存策略 | ScanContext 持有 `ConcurrentHashMap<className, BytecodeAnalysis>` | 1× ASM 解析；规则查 set 即可 |
| 规则数量 | 5 条 | 覆盖设计文档第 9 节字节码关键字 |
| 测试目标 dead-code | `if (System.currentTimeMillis() < 0)` 包裹 | 字节码含 method call，运行时永不执行 |
| 评审遗留 | 仅 #1（删死代码） | #2/#3/#4 推迟 v0.5 |

## 4. 数据流

### 4.1 agentmain 流程（v0.4 增量）

```text
1-6. (不变) AgentArgs / Whitelist / 元信息 / 三个 Scanner
7. 构造 ScanContext (新增 bytecodeCache, lazy-init)
8. RuleEngine.evaluate(allFindings, ctx)
   对每个 finding:
   - v0.3 12 条规则（不变）
   - v0.4 5 条字节码规则：
     第一条字节码规则触发时：
       ctx.bytecodeOf(className)
       ├─ cache hit → 返回（含 MISS sentinel）
       ├─ cache miss → ClassBytecodeReader.readAndAnalyze
       │   ├─ getResourceAsStream("/com/foo/X.class")
       │   ├─ null → 缓存 MISS, 返回 null
       │   ├─ 非 null → ASM ClassReader + Analyzer → BytecodeAnalysis
       │   └─ 异常 → 缓存 MISS, 返回 null
       └─ 返回 BytecodeAnalysis（或 null）
     规则查 BytecodeAnalysis.hasMethodCall(owner, namePattern) → delta
9. Summary + 报告写入（不变）
```

### 4.2 核心数据结构

#### ScanContext（修改）

```java
public class ScanContext {
    public final Object applicationContext;
    public final Whitelist whitelist;
    public final boolean explain;

    // v0.4 新增
    private final java.util.Map<String, BytecodeAnalysis> bytecodeCache =
            new java.util.concurrent.ConcurrentHashMap<>();
    private static final BytecodeAnalysis MISS =
            new BytecodeAnalysis(java.util.Collections.emptySet());

    public ScanContext(Object applicationContext, Whitelist whitelist, boolean explain) {
        this.applicationContext = applicationContext;
        this.whitelist = whitelist;
        this.explain = explain;
    }

    /** Lazy bytecode lookup. Returns null when bytecode cannot be read. */
    public BytecodeAnalysis bytecodeOf(String className) {
        if (className == null) return null;
        BytecodeAnalysis cached = bytecodeCache.get(className);
        if (cached != null) return cached == MISS ? null : cached;

        ClassLoader cl = resolveClassLoader();
        BytecodeAnalysis result = ClassBytecodeReader.readAndAnalyze(className, cl);
        bytecodeCache.put(className, result == null ? MISS : result);
        return result;
    }

    private ClassLoader resolveClassLoader() {
        if (applicationContext != null) return applicationContext.getClass().getClassLoader();
        ClassLoader tccl = Thread.currentThread().getContextClassLoader();
        return tccl != null ? tccl : ClassLoader.getSystemClassLoader();
    }
}
```

#### BytecodeAnalysis（值类型，新建）

```java
public class BytecodeAnalysis {
    /** Strings of form "owner#name", e.g. "java/lang/Runtime#exec" */
    public final java.util.Set<String> methodCalls;

    public BytecodeAnalysis(java.util.Set<String> methodCalls) {
        this.methodCalls = methodCalls;
    }

    /** True if any method call matches owner exactly AND name contains namePattern. */
    public boolean hasMethodCall(String owner, String namePattern) {
        for (String call : methodCalls) {
            int sep = call.indexOf('#');
            if (sep < 0) continue;
            if (call.substring(0, sep).equals(owner)
                    && call.substring(sep + 1).contains(namePattern)) return true;
        }
        return false;
    }

    /** True if any method call's name contains namePattern, regardless of owner. */
    public boolean hasMethodCallByName(String namePattern) {
        for (String call : methodCalls) {
            int sep = call.indexOf('#');
            if (sep < 0) continue;
            if (call.substring(sep + 1).contains(namePattern)) return true;
        }
        return false;
    }
}
```

#### ClassBytecodeReader（新建）

```java
public final class ClassBytecodeReader {
    private ClassBytecodeReader() {}

    public static BytecodeAnalysis readAndAnalyze(String className, ClassLoader cl) {
        if (className == null) return null;
        try {
            String resource = className.replace('.', '/') + ".class";
            ClassLoader loader = cl != null ? cl : ClassBytecodeReader.class.getClassLoader();
            try (java.io.InputStream in = loader.getResourceAsStream(resource)) {
                if (in == null) return null;
                org.objectweb.asm.ClassReader reader = new org.objectweb.asm.ClassReader(in);
                BytecodeAnalyzer analyzer = new BytecodeAnalyzer();
                reader.accept(analyzer,
                        org.objectweb.asm.ClassReader.SKIP_DEBUG | org.objectweb.asm.ClassReader.SKIP_FRAMES);
                return analyzer.toAnalysis();
            }
        } catch (Throwable t) {
            return null;
        }
    }
}
```

#### BytecodeAnalyzer（ASM ClassVisitor，新建）

```java
public class BytecodeAnalyzer extends org.objectweb.asm.ClassVisitor {

    private final java.util.Set<String> methodCalls = new java.util.HashSet<>();
    private static final int ASM_API = org.objectweb.asm.Opcodes.ASM9;

    public BytecodeAnalyzer() { super(ASM_API); }

    @Override
    public org.objectweb.asm.MethodVisitor visitMethod(int access, String name, String descriptor,
                                                       String signature, String[] exceptions) {
        return new org.objectweb.asm.MethodVisitor(ASM_API) {
            @Override
            public void visitMethodInsn(int opcode, String owner, String name, String desc, boolean isIface) {
                methodCalls.add(owner + "#" + name);
            }
        };
    }

    public BytecodeAnalysis toAnalysis() {
        return new BytecodeAnalysis(methodCalls);
    }
}
```

### 4.3 5 条字节码规则契约

| Rule name | 匹配 | Delta |
|---|---|---|
| `bytecode-runtime-exec` | `hasMethodCall("java/lang/Runtime", "exec")` | +4 |
| `bytecode-process-builder` | `hasMethodCall("java/lang/ProcessBuilder", "<init>")` 或 `hasMethodCall("java/lang/ProcessBuilder", "start")` | +4 |
| `bytecode-define-class` | `hasMethodCallByName("defineClass")` | +3 |
| `bytecode-reflection-abuse` | `hasMethodCallByName("setAccessible")` 或 `hasMethodCallByName("getDeclaredField")` 或 `hasMethodCallByName("getDeclaredMethod")` | +2 |
| `bytecode-crypto` | `hasMethodCall("javax/crypto/Cipher", "doFinal")` 或任意调用 owner 以 `java/util/Base64` 开头 | +2 |

### 4.5 Test-target dead-code 设计

`FakeFilter.doFilter()` 中调用 `deadCode()`，该方法用 `if (System.currentTimeMillis() < 0)` 包裹（JIT 不会消除，因为运行时条件；字节码包含 method call）：

```java
private void deadCode() {
    if (System.currentTimeMillis() < 0) {  // never true at runtime
        try {
            Runtime.getRuntime().exec("echo nope");                    // bytecode-runtime-exec
            new ProcessBuilder("nope").start();                         // bytecode-process-builder
            ClassLoader cl = getClass().getClassLoader();
            cl.getClass().getDeclaredMethod("defineClass",
                String.class, byte[].class, int.class, int.class)
                .setAccessible(true);                                   // bytecode-define-class + reflection-abuse
            javax.crypto.Cipher.getInstance("AES").doFinal(new byte[0]); // bytecode-crypto
        } catch (Throwable ignored) {}
    }
}
```

FakeFilter / FakeServlet / FakeInterceptor 各自包含不同 dead-code 组合：

| Fake 类 | 触发规则 |
|---|---|
| FakeFilter | runtime-exec, process-builder, reflection-abuse |
| FakeServlet | runtime-exec, crypto, reflection-abuse |
| FakeInterceptor | runtime-exec, define-class, reflection-abuse, crypto |

合计触发统计（用于 §6.3 验收）：
- bytecode-runtime-exec: 3 (FakeFilter + FakeServlet + FakeInterceptor)
- bytecode-process-builder: 1 (FakeFilter)
- bytecode-define-class: 1 (FakeInterceptor)
- bytecode-reflection-abuse: 3 (FakeFilter + FakeServlet + FakeInterceptor)
- bytecode-crypto: 2 (FakeServlet + FakeInterceptor)

这样能验证规则**独立**触发（不同组合不互相干扰）。

## 5. 错误处理

- `ClassBytecodeReader.readAndAnalyze` 内部 try-catch Throwable，失败返回 null
- ScanContext 缓存 null sentinel 避免重复尝试
- ASM ClassReader 解析失败（字节码版本太新等）也通过 Throwable catch 兜底
- 任何字节码规则在 `ctx.bytecodeOf` 返回 null 时安静返回 0

## 10. 实施约束

- 每条字节码规则文件 ≤ 50 行
- BytecodeAnalyzer ≤ 60 行
- 所有规则严格只读 ctx，不修改任何字段
- 失败必须返回 0，不抛异常
- 字节码读取必须用 ClassBytecodeReader，不允许规则内部直接调用 ASM
- 测试覆盖：每条规则至少 2 个测试（命中 + 不命中）
